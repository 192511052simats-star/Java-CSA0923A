PROGRAMMING IN JAVA – ASSIGNMENT 2 (CO2)
Starter project for Q1–Q7

IMPORTANT
- This ZIP contains runnable starter implementations and experiments for all seven questions.
- Run each task on your own Mac. Do not submit made-up timings. The programs write CSV files with measurements from your machine.
- Take Terminal screenshots showing each task's output. For benchmark questions, keep the generated CSV files too.
- Review the analysis notes and adapt the reasoning to your own observed results before submission.
- Java version recommended: Java 17 or later. Check with: java -version

MAC SETUP
1. Extract this ZIP.
2. Open the extracted CO2_Java_Assignment2_Starter folder in VS Code.
3. Open Terminal and cd into the extracted folder.
4. Run one task at a time using the commands in each Task folder's README.txt.
5. For every benchmark, run it more than once if instructed and retain the CSV output.

TASKS
Q1 String / StringBuilder / StringBuffer benchmark
Q2 ArrayList / LinkedList / ArrayDeque experiments
Q3 HashSet equals/hashCode contract (broken and corrected cases)
Q4 HashMap / TreeMap / LinkedHashMap comparison
Q5 Generic Leaderboard and comparator
Q6 Hospital triage PriorityQueue and growth experiment
Q7 Diagnose and validate a redesign: ArrayList front-removal vs ArrayDeque

OUTPUTS
Each task writes CSV data to its own folder when you execute it. These are your raw experimental data.
The folder Output_Screenshots is provided for your screenshots. Save your actual screenshots there.
