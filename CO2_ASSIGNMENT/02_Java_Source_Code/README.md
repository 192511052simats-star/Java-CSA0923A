# CO2 Java Assignment 2 – Q1 to Q7

Individual Java assignment starter project.

## Environment
- Java: record the version shown by `java -version`
- Build: standard `javac`
- No third-party libraries required

## Tasks
| Folder | Topic | Main class |
|---|---|---|
| Q1 | String, StringBuilder, StringBuffer | `StringBenchmark` |
| Q2 | ArrayList, LinkedList, ArrayDeque | `ListBenchmark` |
| Q3 | `equals()` and `hashCode()` contract | `AttendanceDemo` |
| Q4 | HashMap, TreeMap, LinkedHashMap | `MapBenchmark` |
| Q5 | Generics and Comparator | `LeaderboardDemo` |
| Q6 | PriorityQueue triage | `TriageDemo` |
| Q7 | Diagnose, redesign and validate | `QueueRedesignBenchmark` |

Compile and run each task from its own folder as described in that folder's README.txt.

## Evidence to retain
- Terminal screenshots of successful executions.
- CSV files generated by benchmark programs.
- Your own written predictions, observed results, analysis and design decisions.
- Do not treat a single timing as conclusive; compare repeated measurements and note machine/JVM conditions.
