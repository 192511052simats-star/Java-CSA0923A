# CO3 – Programming in Java Assignment 3

This repository starter follows the seven tasks in the supplied Assignment CO3 Java PDF:
1. ATM exception handling
2. User-defined exceptions and propagation
3. Resource safety and try-with-resources
4. Thread creation and lifecycle
5. Race conditions and synchronization
6. Deadlock and producer-consumer communication
7. Concurrent fault-tolerant result processing

Use Java 21 or compatible. Each task folder contains source code and a task README.
Complete the additional analysis and individual Student A / Student B evidence required by the assignment.
