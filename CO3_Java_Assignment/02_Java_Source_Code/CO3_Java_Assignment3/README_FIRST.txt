PROGRAMMING IN JAVA – ASSIGNMENT 3 (CO3)
Runnable starter project for Questions 1–7

IMPORTANT
- This package is based on the uploaded Assignment CO3 Java.pdf (11 pages).
- Each question has its own folder, Java source, README, and expected-output notes where useful.
- These are runnable learning implementations to help you execute and collect evidence. The written assignment still requires your own analysis, test tables, stack traces, debugging evidence, repeated-run observations, and Student A / Student B contribution sections.
- Run each program from its own task folder. Use Java 21 (or a compatible modern JDK).
- In Terminal, first cd into the extracted CO3_Java_Assignment3_Starter folder.

GENERAL RUNNING
For a single-file task:
  javac FileName.java
  java ClassName

For Task 3, Task 6 and Task 7, use the exact commands in each task README.

SCREENSHOTS TO COLLECT
- Capture full Terminal output for each question.
- Task 1: valid withdrawal, invalid number, negative amount, insufficient funds, and missing card-reader file.
- Task 2: normal save and quota-exceeded case showing getCause().
- Task 3: report output and evidence that resources are closed on failure.
- Task 4: output from at least 10 runs; record station completion order and a priority experiment.
- Task 5: unsynchronized and synchronized outputs; repeat unsynchronized runs and record any double bookings.
- Task 6: producer-consumer result; optional deadlock demonstration and deadlock-prevention result.
- Task 7: pool sizes 1, 2, 4 and 8; CSV and summary counts.
